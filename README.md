# Bazi Analysis Skill — 八字命理分析引擎 v2.0.0

结构化八字排盘、命局分析与大运流年推演助手。本地脚本精确排盘（立春/节气秒级分界 + 真太阳时校正），盲派体用做功体系十一步推演流程，HTML 报告交付。严格遵循理法物理引擎，拒绝套话与幻觉。

## 核心特性

- **本地排盘引擎（唯一事实源）**：`scripts/paipan.py` 基于 sxtwl 计算——年柱立春分界、月柱交节分界精确到秒；十神、藏干、十二长生、空亡、纳音、神煞、起运、十步大运、流年全部脚本产出，模型禁止手推。
- **真太阳时校正**：提供出生地经度即启用（经度平太阳时修正 + 均时差），原 v1.x 的外部 API 无此能力。
- **十一步推演流程**：排盘与意图路由 → 原局结构 →（验前事校验）→ 气象调候 → 格局判断 → 寻根权属 → 做功结构 → 大运流年 → 综合策略 → 子代理审查 → HTML 报告。每步「准入条件 → 强制加载 → 分析 → 强制输出 → 落盘 → 检查点」六段骨架，禁止跳步。
- **领域资料按需加载**：核心法则、四墓库、比劫规则、天干五合、地支互动与十二长生、穷通宝鉴调候全书（41 篇）、时代印记，由 SKILL.md 的单一权威触发表调度，读取须留痕。
- **防幻觉机制**：读取参考文件必须摘录关键句（假合规检测）；✋结转只写案例文件；独立子代理逆向审查；报告先 `--validate` 后交付。
- **HTML 报告**：四柱盘面、起运大运、流年、神煞、推演全文附录，宣纸风格、打印友好。

## 使用模式

| 模式 | 触发语例 | 行为 |
|---|---|---|
| 完整分析 | "全面分析这个八字""系统解读命局与大运" | 十一步全流程 + HTML 报告 |
| 单点问答 | "财运如何？""2027 年能不能换工作？" | 只做相关步骤，简版四段输出 |
| 排盘确认 | 只给出生时间，"帮我排个盘" | 排盘卡 + 起运大运 + 下一步选项 |
| 信息不足 | 缺时辰/性别/出生地 | 最少澄清问题，不强行补全 |

## 使用示例

```
用户：帮我全面看一下这个八字：乾造 庚午 壬午 辛亥 乙未，起运 1997 年，
     现在走乙酉大运，出生地上海。
AI：  （路由：完整分析）建立案例目录 → 排盘交叉校验 → 十一步流程 →
     report.html
```

```
用户：1990-06-15 14:30 上海，男，2026 年运势怎么样？
AI：  （路由：单点问答，问题落在流年）排盘（含真太阳时校正）→
     相关结构步骤 → 2026 丙午流年简版分析（大运环境绑定）
```

## 输入要求

| 信息 | 必要性 | 说明 |
|---|---|---|
| 四柱八字 或 出生时间 | 必需 | 二选一；只有出生时间时脚本自动排盘 |
| 性别（乾造/坤造） | 必需 | 决定大运顺逆 |
| 出生地（市/区县） | 强烈建议 | 用于真太阳时校正；狭长地形建议精确到区县 |
| 时辰 | 必需 | 缺时辰时脚本标记 `hour_missing`，AI 必须先澄清 |
| 起运/大运（已有排盘时） | 可选 | 用于与脚本结果交叉校验 |

## 排盘约定（引擎 conventions 字段同步记录）

- 年柱与流年以立春交节时刻分界；月柱以节交节时刻分界，月干按"最近一次立春"锚定五虎遁
- 晚子时（23:00–24:00）：日柱按当日，时干按次日日干五鼠遁（夜子时派）
- 十二长生采用火土同宫（丙戊同宫、丁己同宫）
- 起运按周岁折算（3 天 = 1 年），起运年份 = 出生年 + 折算年数
- 羊刃只取阳干

## 局限与边界

- 命理分析供决策参考，不替代专业意见；医疗、法律、投资等重大决策请咨询专业人士。
- 时代印记资料覆盖 1980–2026，其后年份无时代数据，涉及推断会明确说明。
- 出生年份超出 sxtwl 支持范围时排盘失败，AI 会向用户索要排盘结果而不是编造。
